# Telegram Mini App — 23КСК-4

Статическое Mini App с тёмным интерфейсом и расписанием, перенесённым из загруженного `bot.py`.

## Что работает
- Сегодня и завтра (по локальной дате устройства)
- Расписание всех четырёх учебных недель
- Расписание звонков для будней и субботы
- Выбор даты календарём
- Адаптация под Telegram Web Apps и мобильный экран

## Важно о данных
В исходном расписании данные есть только за 30.11.2026–26.12.2026. За другие даты приложение честно показывает, что расписание не загружено. Воскресные даты не добавлены в учебные недели.

## Публикация бесплатно
Это статический сайт: сервер Python и постоянно работающий процесс не нужны. Можно разместить папку на GitHub Pages:
1. Создать публичный репозиторий GitHub.
2. Загрузить в корень все файлы этой папки (`index.html`, `style.css`, `app.js`, `data.js`).
3. В репозитории открыть **Settings → Pages**.
4. В разделе **Build and deployment** выбрать **Deploy from a branch**, ветку `main` и папку `/ (root)`, сохранить.
5. Дождаться публикации и скопировать URL вида `https://USERNAME.github.io/REPOSITORY/`.

## Подключение к Telegram
1. Открыть `@BotFather` → выбрать своего бота.
2. Использовать `/setmenubutton` (если доступно в меню BotFather) и указать URL опубликованного Mini App; либо настроить Main Mini App в настройках бота.
3. Открывать приложение через кнопку меню бота.

Mini App не содержит токена бота и не отправляет данные на сторонний сервер. Для показа расписания бот-процесс не требуется; нужен только URL, доступный по HTTPS.
